# Components and map style (phase 3)

Inputs: `replica/01-recon/recon.md` (component list), `replica/02-architecture/architecture.md`.
Tokens: `tokens.json` → `tokens.css` (generated by `build_tokens.py`). Contrast: `contrast-report.txt`, **94/94 pairs pass WCAG AA** across dark, light and a11y.
Preview: `preview.html` (+ `map-style.js`, `serve.mjs`); screenshots in `screens/` (D01–D06).
Own design: no Giga colours, logos, icons or copy. Icons: **Lucide** (ISC licence) in phase 4. Fonts: **Noto Sans / Noto Sans Sinhala / Noto Sans Tamil** (OFL), self-hosted.

## Themes

| theme | when | notes |
|---|---|---|
| `dark` (default) | first run, `prefers-color-scheme: dark` or no preference | The Strava-like look: warm glowing roads on near-black. |
| `light` | user choice or system light | Glow reduced to 35 %, no core highlight. |
| `a11y` | Accessibility mode switch | Black base, white/yellow roads without glow, Okabe-Ito status colours (blue = connected, orange = not connected, grey = unknown), larger focus ring (yellow). Status is never colour-only: see School dot. |

Language: `[lang=si]` / `[lang=ta]` adds +4 px line height to every step of the type scale (taller scripts).

## Map style (`map-style.js`)

Base: `background` = `map-land`. **Phase 4 adds `base.pmtiles`** (water, coastline, admin boundaries, place labels). Without it the sea and the land have the same colour (seen in D01–D06).

Roads, from the `roads` source layer, by `class`:

| class | colour token | min zoom | width z8 / z12 / z14 / z16 (px) | glow | style |
|---|---|---|---|---|---|
| motorway | `road-motorway` | 5 | 2 / 4 / 7 / 14 | 1.0 | + bright core from z11 |
| trunk | `road-trunk` | 5 | 1.8 / 3.5 / 6 / 12 | 0.9 | + core |
| primary | `road-primary` | 5 | 1.4 / 3 / 5 / 10 | 0.8 | + core |
| secondary | `road-secondary` | 8 | 0.9 / 2.4 / 4 / 8 | 0.6 | |
| tertiary | `road-tertiary` | 10 | – / 1.8 / 3.2 / 6 | 0.4 | |
| unclassified | `road-unclassified` | 11 | – / – / 2.2 / 4.5 | – | opacity 0.85 |
| residential | `road-residential` | 12 | – / 0.5 / 1.8 / 4 | – | opacity 0.7 |
| service | `road-service` | 12 | – / 0.4 / 1.2 / 3 | – | opacity 0.6 |
| track | `road-track` | 12 | – / 0.5 / 1.4 / 3 | – | dashed 3-2 |
| cycleway | `road-cycleway` | 13 | – / – / 1.2 / 2.4 | – | dashed 2-1 |
| path, footway, steps | `road-path` | 13 | – / – / 1 / 2 | – | dotted 1-1.5 |
| construction | `road-construction` | 13 | – / – / 1.2 / 2.4 | – | dashed 2-2 |
| other | `road-other` | 13 | – / – / 0.8 / 1.6 | – | opacity 0.6 |

- Widths interpolate exponentially (base 1.6). `link=true` ways are drawn at 0.6× width. `tunnel=true` ways are drawn at 45 % opacity, without glow.
- **Glow**: a wider, blurred copy under the major classes (4× width, blur 3× width, opacity 0.22 × glow). Overlapping roads brighten, which gives the heat-map feel.
- **Draw order**: minor first, major on top (`line-sort-key` = rank).
- **Toggle groups** (UI chips): major = motorway–secondary; local = tertiary–service; rural = track; active = path and cycleway; other = construction and other. Default on: major, local.
- **Labels**: road names from z13 using `name:en` with a fallback to `name`. Glyphs must be self-hosted (Noto Sans Regular) in phase 4. Sinhala/Tamil names are not used on the map (MapLibre cannot shape these scripts).
- **Bounds**: `SRI_LANKA_BOUNDS` = [[78.9, 5.4], [82.9, 10.3]], min zoom 6.
- **Map padding**: on desktop, when the side panel is open, set `map.setPadding({ left: panel-width + 2 × gutter })`, so the island is not hidden behind the panel (in D01 the west coast is under the panel).

Schools (GeoJSON source `schools`, property `status`):

- Circle radius 1.6 (z6) → 4 (z12) → 7 (z15) → 10 (z17). 1 px stroke in `school-stroke`.
- Fill: `status-connected` / `status-not-connected` / `status-unknown`. All schools are `unknown` for now, so the map shows neutral grey-blue dots that never read as "bad".
- A11y mode adds a **shape cue**: in phase 4 not-connected schools become hollow rings and connected schools filled dots, so status does not rely on colour alone.
- Selected school: an extra ring in `selected`, 3 px wide.
- Low zoom (≤ 8): 10k dots read as density. They are not clustered, because the density pattern is informative and renders fine (≈1.6 s to idle in the preview).

## Components

Every interactive element has a real element (`button`, `input`, `a`), a visible `:focus-visible` ring (2 px `focus`, offset 2), and a minimum hit area of 44 × 44 px on touch.

```
AppShell
  layout    desktop ≥ 900: map full-screen + docked SidePanel (left, 340 px, gutter 12) + MapControls (right)
            640–900: SidePanel 300 px
            < 640: TopBar (menu + SearchBox) + BottomSheet + MapControls (right, above sheet)
  tokens    bg, surface, border, shadow-pop, radius-lg
  used on   all

SidePanel (desktop)
  states    expanded, collapsed (edge tab 16×48 px with chevron, label "Hide panel"/"Show panel")
  a11y      <aside aria-label>, collapse button aria-expanded, focus moves to the tab on collapse
  used on   S09, S10, S14

BottomSheet (mobile)
  snap      peek 96 px (title + close) · half 50dvh · full (minus TopBar)
  states    dragging, snapped; respects prefers-reduced-motion (no spring animation)
  a11y      drag handle is a <button> "Resize panel" that cycles the snap points with Enter/Space;
            Escape returns to peek
  used on   S15 and every mobile view

TopBar (mobile)
  contents  menu button, SearchBox (full width); FacilityChips scroll horizontally below it
  note      search sits at the top, not inside the sheet (fix of preview D06)

SearchBox
  states    empty (placeholder "Search a school or district"), typing, results, no results, clear
  behaviour 150 ms debounce; accent/case-insensitive; prefix matches rank first; max 50 results
  a11y      role=combobox + listbox; ↑/↓ moves, Enter opens, Escape clears; result count announced via aria-live=polite
  used on   S08–S10

ResultRow
  variants  school (name + district, province), area (district or province)
  states    default, hover, active (keyboard), focus
  tokens    text, text-muted (secondary line), surface-raised hover

Breadcrumb
  levels    Sri Lanka › Province › District › School; middle levels collapse to "…" under 300 px
  a11y      <nav aria-label="Breadcrumb">, last item aria-current="page"

StatCard
  variants  KPI trio (total / connected / with speed data), collapsible section
  states    expanded, collapsed, no-data (value "–" with an explanation)
  tokens    surface-raised, border, radius-md, font lg/600 for numbers

BigMetric
  value + unit + info button (tooltip)
  states    good / moderate / bad / unknown (text in speed-* tokens), no-data ("No data yet" in speed-unknown)
  note      the colour is never the only cue: the bucket name is written next to the value

DataNotice
  a warning bar (3 px left border in `warning`) with a short explanation
  used      when the connectivity data is missing; when the data is older than 30 days ("Data from <date>")

WeekNavigator
  prev · range label · next · jump-to-latest; disabled at the bounds
  hidden until a ConnectivityProvider supplies measurements

SegmentedTabs
  weekly / monthly; role=tablist, arrow keys move

SpeedChart
  bars in `chart-bar`; benchmark line (20 Mbps) in `chart-benchmark`, dashed; date axis
  states    filled, empty ("No measurements for this period")
  a11y      a <table> fallback for screen readers (visually hidden)

LayerTile + LayerPicker
  tile      icon + label + info button
  states    active (accent bg / on-accent text), inactive, disabled (no data, tooltip explains)
  groups    "Live data" and "Reference layers"; for Sri Lanka only Status is enabled until private data exists

Legend
  sections  School status (3 rows) · Roads (8 rows, swatch with glow) · counts per status when data exists
  states    shown, hidden (toggled from MapControls); on mobile it lives inside the sheet
  interactive rows: checkbox + label + count, toggling filters the map

MapControls
  zoom in, zoom out, locate me (optional), accessibility, theme & layers, legend
  size      40 px desktop, 44 px touch; stacked vertical; tooltips on hover/focus

FacilityChips / RoadChips
  toggle buttons with aria-pressed; selected = accent bg + on-accent text
  RoadChips: Main · Local · Tracks · Paths · Other (ROAD_GROUPS)

Switch
  role=switch, aria-checked; on = accent; label always visible

RadioGroup
  theme (dark/light/system) and basemap (default/street)

Select (filters)
  native <select> styled; options: education level (Primary / Secondary / Primary and Secondary), province, district

Dialog / Popover / Drawer
  Dialog   modal, focus trap, Escape closes, returns focus to opener (Share, About data, Offline)
  Popover  non-modal (Accessibility, Layer picker)
  Drawer   right side, desktop filters; full-screen sheet on mobile
  tokens   surface, border, shadow-pop, radius-lg

MapPopup (school)
  name, district, status badge, data age, "Open details" link
  a11y     focusable, Escape closes; on mobile it opens the sheet instead of a popup

OfflinePanel (new, PAE)
  rows     App · Roads map (37 MB) · Base map (~15 MB) · Schools (0.3 MB): each with size, status (not downloaded / downloading x % / ready, date) and an action
  extras   storage used / available (navigator.storage.estimate), "Keep offline data" (persist) toggle
  states   idle, downloading (progress bar, cancel), done, error (retry), insufficient storage

Toast
  aria-live=polite, 4 s, dismissible; used for "Link copied", "Map ready offline"

AttributionBar
  always visible: "© OpenStreetMap contributors" (link) · "Schools: Giga" · data date
```

## States the recon did not see (designed anyway)

| state | design |
|---|---|
| Search: no results | "No schools match "<q>"" + hint to try a district name |
| Loading | skeleton rows in the panel; the map shows roads while schools load |
| Offline, no map downloaded | full-screen notice with the OfflinePanel action; search and list still work from the schools snapshot |
| Data error (schools.json missing or corrupt) | DataNotice in `danger` + retry; keep the last good snapshot |
| Accessibility mode ON | a11y theme (D05) |
| Low storage | OfflinePanel shows the required vs available MB and disables the download |

## Gate (phase 3)

| criterion | result |
|---|---|
| WCAG AA for the UI in every theme | **PASS**: 94/94 pairs (`contrast-report.txt`) |
| Road classes distinguishable at every zoom | **PASS** (visual): z7 major only (D01), z11 tertiary up (D03/D04/D05), z13 all classes (D02). Colour, width, glow and dash all differ by class. |
| Colour-blind safe | **PASS**: a11y theme uses Okabe-Ito colours; status adds a shape cue; road classes differ in width and dash as well as colour |
| Original assets | **PASS**: own palette, own copy, open fonts (OFL) and icons (Lucide, ISC); no Giga or Strava assets |
| Primitives built in isolation | **PASS (preview level)**: `preview.html` renders the panel primitives and the real map style. Preact components are built in phase 4 M1. |
